# Flip 7

A pass-and-play version of the Flip 7 card game for 3 to 10 players, in a single HTML file.

- Full 94-card deck: numbers 0–12, modifiers (+2 to +10, ×2) and action cards (Freeze, Flip Three, Second Chance)
- Bots with three play styles (Cautious, Balanced, Bold) to fill empty seats or add opponents
- Any seat can be handed to a bot mid-game
- Race to 200 points

## Play

Open `index.html` in a browser, or serve the folder locally:

```
python3 -m http.server 8080
```

then visit http://localhost:8080.
